Say hello to Saylo.

Real-time multilingual conversational voice AI, with a free browser demonstration and a preserved self-hosted voice runtime.

What Saylo adds

A complete live transcript, bounded local conversation history, an extractive recap with copy support, and a browser voice demonstration. No account, database, or paid API is required for the demo.

Two distinct experiences

The free browser demo uses browser speech recognition where supported, speech synthesis, and simple local replies. Typed input always works. Audio recognition may be processed by your browser vendor. It is not the full AI runtime.

The original Go runtime uses WebRTC or Twilio, adaptive speech recognition, an application agent, and a Python voice router. It needs separately configured providers and hardware. See the repository’s README and preserved technical documentation for setup.

Runtime

The self-hosted voice runtime is built on StreamCore and is licensed under Apache 2.0.

Your conversations

Up to 20 recent conversations are stored in localStorage on this browser. Clear all or delete individual entries in the demo. Private browsing, blocked storage, or a full quota can prevent persistence. This is not encrypted storage. No audio is saved by Saylo.
